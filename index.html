㈜열림데이터시스템 · DONGKUK SYSTEMS

한 주의 업무를 한 곳에서

네트워크부문과 ITOA 부문의 주간업무보고를 여러 사람이 함께 작성하고, 보고서(PPT · 엑셀)로 바로 출력하는 사내 웹 시스템입니다.

사업장별 동시 작성전체 현황 · 독촉 메일PPT · 엑셀 출력손글씨 서명주간보고 점검Wiki 검색문의 및 제안
⚠ 이 페이지는 소개와 사용자 매뉴얼입니다. 실제 주간업무보고는 사내 서버에서 동작하므로 회사 네트워크에서 관리자에게 받은 접속 주소(예: http://10.90.9.201:3000)로 들어가세요.

주요 기능

네트워크부문 주간보고

  • DK GROUP 운영 업무 건수 · 변경/신규 업무 · 장애/이슈
  • 담당 사업장만 작성, 전주 불러오기
  • 미리보기 · 인쇄, 주간보고서 PPT, 월간 보고

ITOA 주간보고

  • 사업장별 처리 실적 · 백신/방역 · 근무 현황
  • 담당 · 팀장 손글씨 서명 → 자동 완료
  • 통합 엑셀 (V3 현황 · 사업장 시트 · 색인)

관리

  • 전체 현황과 미완 사업장 독촉 메일
  • 사용자 · 부문 · 사업장 · 담당자 관리
  • 보고서 확정, 자동 백업 · 복원

함께 쓰기

  • 현재 접속자와 입력 중인 칸 표시
  • 맞춤법 · 띄어쓰기 점검, Wiki 검색
  • 문의 및 제안 게시판 (첨부 · 메일 알림)

사용자 매뉴얼

서버 실행 (관리자)

Node.js가 설치된 사내 PC에서 실행합니다. 데이터는 data/ 폴더에 저장되며 저장소에는 올라가지 않습니다.

npm install
node server.js          # http://localhost:3000 (다른 PC: http://이PC의IP:3000)
install-autostart.bat   # PC 로그인 시 자동 실행 · 꺼지면 다시 켜기
