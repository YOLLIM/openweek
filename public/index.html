보고서 기본 정보



메일 발송 설정 (독촉 메일)

전체 현황의 독촉 메일을 보낼 회사 메일 서버(SMTP) 정보입니다. 주소·포트·계정은 전산 담당자에게 확인하세요. 비밀번호는 서버에만 저장되고 화면에는 다시 표시되지 않습니다.


AI 점검 (선택 사항)

주간보고 점검은 키 없이도 서버의 기본 규칙(자주 틀리는 맞춤법·띄어쓰기·문장부호)으로 동작합니다. Anthropic Claude API 키를 등록하면 AI 점검 결과가 함께 표시되어 더 많은 오류를 찾습니다. 이때 보고서 문장이 Anthropic으로 전송되며 사용량만큼 요금이 발생합니다. 키는 서버에만 저장됩니다.
상태: 확인 중…

데이터 백업 / 복원

데이터는 서버의 data/db.json에 저장되며, data/backup에 하루 한 번 자동 백업됩니다. 내보낸 JSON 파일로 언제든 복원할 수 있습니다(가져오기는 모든 사용자에게 적용).

자동 백업에서 복원 (관리자)

하루 한 번 자동으로 만든 백업 중 하나로 전체 데이터를 되돌립니다. 복원 직전 상태도 따로 백업해 두므로 다시 되돌릴 수 있습니다. 사용자 계정·변경 이력·첨부 사진은 영향을 받지 않습니다.
보고일이 선택한 달에 속하는 주간보고를 합쳐 봅니다. 운영 업무 건수는 합계, 글 항목은 주차별로 모아 엑셀·PPT로 받을 수 있습니다.
